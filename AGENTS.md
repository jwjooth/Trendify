## Commands (use these exactly)

- Dev / build / serve: `npm run dev` (`next dev` → :3000), `npm run build` (`next build`), `npm run start`
- Lint: `npm run lint` (`eslint .` — flat `eslint.config.js`; legacy `.eslintrc.json` is dead)
- Typecheck: `npm run typecheck` (`tsc --noEmit`, strict + `noUnusedLocals/Parameters`)
- Tests: `npm run test` (`vitest run`); single file: `npx vitest run <path>`; setup: `src/test-setup.ts` (jsdom, globals)
- README's `localhost:5173` / Vite dev claims are stale — Next on :3000 is real. `vite.config.ts` + `src/main.tsx` are legacy (only Vitest still uses the vite plugin).

## Architecture

- Entry: `pages/*.tsx` → re-export from `src/app/**`. **`pages/` is gitignored** — generated by `setup-pages.js`; never edit it, edit `src/app/**`.
- Real code: `src/app/features/{products,cart,checkout,marketing}/` (domain pages), `src/app/shared/{layout,ui,hooks}/` (Header/Footer/Layout/ErrorBoundary, vendored shadcn/Radix in `ui/`), `src/app/service/` (products/categories/faqs/testimonial/user/auth, barrel in `service/index.ts`), endpoints centralized in `src/app/lib/service-url.ts`.
- Legacy path (don't extend): `src/main.tsx` → `src/app/App.tsx` (`RouterProvider` + `src/app/router/`). Next path uses `src/app/shared/layout/_app.tsx` (`CartProvider` + Header/Footer + Toaster).
- Alias: `@/*` = `./src/*` (tsconfig + vitest). `jsx: preserve` (Next).

## Env / data

- `NEXT_PUBLIC_*` only (`service-url.ts` reads them with public MockAPI fallbacks — app runs with no `.env`). Copy `.env.example` → `.env.local` to override. Never commit secrets (`.gitignore` covers `.env*`).
- `src/app/utils/security/index.ts` uses `import.meta.env` — Vite-only idiom, undefined under Next; prefer `process.env.NEXT_PUBLIC_*` in new code.

## Conventions / gotchas

- `src/app/shared/ui/` is vendored shadcn — don't refactor for style; `react-hooks/set-state-in-effect` + `react-hooks/purity` are warn-only there by design.
- Only one test exists (`ContactForm.test.tsx`); no services/fixtures needed.
- Lockfiles: `bun.lock` + `package-lock.json` + `yarn.lock` coexist; Dockerfile/Jenkins use **bun** (`bun install --frozen-lockfile`). Jenkins `bun test` invokes Bun's runner, not Vitest — use `bun run test` / `npm run test` for Vitest.
- No `.github/workflows`, no `opencode.json`.
